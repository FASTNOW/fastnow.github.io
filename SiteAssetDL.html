SiteAssetDL

页面资源嗅探 · 批量下载 · 流式打包

油猴脚本 图片/视频/音频/字体/字幕 懒加载扫描 并发下载 ZIP 流式打包

页面资源全嗅探 —— 图片、视频、音频、字体、字幕，甚至 CSS 背景和懒加载内容，一键批量下载或打包为 ZIP
安装 SiteAssetDL

需要 Tampermonkey 或 Violentmonkey · 支持 Chrome / Firefox / Edge

核心功能

  • 全类型嗅探 – 图片、视频、音频、字体、字幕，自动识别扩展名与 MIME
  • 深度扫描 – 强制解冻懒加载、滚动触发图片、CSS 背景、字体、iframe 资源
  • 智能去重 – 基于 URL 和尺寸/大小指纹，标记重复项，一键清理
  • 并发批量下载 – 可调并发数与重试，失败自动降速，断流重试
  • 流式直写 ZIP – 利用 File System Access API 直接写入磁盘，支持超大文件
  • 原生压缩 – 对文本类资源（字幕、CSS、JSON）自动 Deflate 压缩，已压缩格式跳过
  • 多格式导出 – URL 列表、aria2 输入、wget/curl 脚本、Markdown、CSV、JSON
  • 悬浮面板 – 可拖拽、缩放，适配触摸与桌面，快捷键 Alt+S 开关
  • 悬停预览 – 鼠标悬停图片卡片即可预览大图，双击全屏浏览
  • 跨页持续 – 监听 pushState / hash 变化，SPA 页面自动重新采集

安装与使用

  1. 安装浏览器扩展 Tampermonkey 或 Violentmonkey
  2. 点击上方 安装 SiteAssetDL，油猴弹出安装界面，点击“安装”
  3. 打开任意网页（推荐图片/视频站，如 unsplash.com、pixabay.com）
  4. 右下角出现 “嗅探” 悬浮按钮，单击打开面板
  5. 面板自动展示当前页所有资源，可按类型、大小、域名、懒加载等筛选
  6. 勾选需要的资源，点击 “打包 ZIP” 或 “逐个下载” 即可
深度扫描 按钮会强制解冻懒加载图片、自动滚动页面，触发更多隐藏资源
存到文件夹 功能（需浏览器支持 showDirectoryPicker）可流式写入，不占内存

配置项

  • 下载并发数 – 默认 6，连续失败自动降速
  • 失败重试次数 – 默认 2，对 403/404 等永久错误跳过
  • ZIP 压缩 – 智能（自动压缩文本类）/ 不压缩（最快）/ 全部压缩（最小）
  • 分组显示 – 按类型或域名分组，浏览更清晰
  • 主题 – 浅色/深色/跟随系统
  • 去重忽略参数 – 忽略 URL 查询参数，合并相同资源
  • 悬停预览 – 鼠标悬停图片卡片快速预览
  • 自动滚动 – 深度扫描时自动滚动触发懒加载
  • 追踪无限滚动 – 对无限滚动页面持续加载
  • 记住窗口位置 – 面板位置和大小会保存到 GM 存储

风险与注意事项

  • 全域匹配 – 脚本默认在所有网页生效，建议在设置中 不要 填写白名单（该脚本无站点限制，但请勿在隐私页面使用）
  • 大量下载 – 批量下载数百个文件可能触发浏览器限流或站点反爬，请合理设置并发数
  • 跨域资源 – 部分站点可能拒绝跨域请求，此时可尝试“逐个下载”触发浏览器原生下载
  • ZIP 内存 – 打包时所有文件会暂存内存，若资源总大小超过 2GB，建议使用“存到文件夹”或分批下载

常见问题

嗅探不到某些图片/视频？
尝试点击 “深度扫描”，脚本会强制解冻懒加载、滚动页面并扫描 CSS 背景若仍缺失，可手动滚动页面后点击“重新采集”
打包 ZIP 时提示“文件数超过 65535”？
ZIP 格式限制最多 65535 个文件，请分批选择或使用“存到文件夹”直接写入磁盘
下载大文件时内存占用高？
使用 “存到文件夹” 功能（需浏览器支持 File System Access API），文件会流式写入磁盘，不占用内存
如何导出资源列表？
在面板底部选择导出格式（txt / aria2 / wget / curl / md / csv / json），点击即可下载文件
能下载 M3U8 或流媒体吗？
脚本会嗅探 M3U8 / MPD 索引文件，但不会解析切片您可复制 URL 后使用其他工具下载
脚本会收集我的浏览数据吗？
不会所有数据仅在本地处理，不发送任何外部服务器（除了资源下载请求）
