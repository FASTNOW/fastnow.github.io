FKQuestions

问卷辅助 · AI 自动填写

油猴脚本 AI 辅助 跨页续填 拟人输入

自动识别问卷题目 → 调用 AI 生成自然答案 → 逐字填写 → 自动翻页，全程像真人操作
安装 FKQuestions

需要 Tampermonkey 或 Violentmonkey

功能特性

  • 题目提取 – 单选、多选、填空、下拉、日期、滑块、取色器、文件上传、富文本等 10+ 种题型，自动屏蔽页面噪声
  • AI 生成答案 – 支持 OpenAI / DeepSeek / 智谱 / Claude / Gemini / 自定义端点，可设人设和自定义提示词
  • 拟人输入 – 逐字键入，随机间隔、卡壳、思考，速度可调（关闭/快/正常/慢）
  • 反作弊扫描 – 只读检测验证码、蜜罐、陷阱题、风控 SDK、行为监听，风险高时自动降级为“仅建议”
  • 跨页续填 – 支持整页跳转、SPA（pushState）和纯 AJAX 换页，自动点“下一页”直到提交
  • 独立答案窗 – 可拖拽、收起，逐题复制或一键复制全部答案
  • 执行日志 – 记录提取、AI 请求、填写过程，仅内存存储，不落盘
  • 配置导入/导出 – 迁移设置（含 Key）只需一次导出导入
  • 快捷键 – Alt+Q 开关面板，Alt+W 执行，Alt+E 预览题目

安装与使用

  1. 安装浏览器扩展 Tampermonkey 或 Violentmonkey
  2. 点击上方的 安装 FKQuestions，油猴会自动弹出安装界面，点“安装”即可
  3. 打开问卷页面（推荐先试 *.wjx.cn、wj.qq.com）
  4. 右下角出现齿轮图标，单击打开面板，在 AI 页填入 API Key
  5. 在 填写 页选模式：
    • 全自动 – 直接填，不确认
    • 半自动 – 预览后确认再填（推荐）
    • 仅建议 – 只显示答案，不碰页面
  6. 点 执行 开始若开启 跨页，会自动翻页直到结束
  7. 若开启“自动提交”且无风险，3 秒后自动点提交按钮

配置项

  • 执行模式 – 全自动/半自动/仅建议
  • 自动提交 – 受反作弊等级限制
  • 打字速度 – 关闭/快速/正常/慢速
  • 人设 – 学生/白领/设计师/教师/程序员/普通用户 + 自定义提示词
  • 答案约束 – 多选最少/最多项，填空最大字数
  • 反作弊敏感度 – 宽松/标准/严格
  • 媒体检测 – 可关闭，避免图标密集页面误降级
  • 站点白名单 – 强烈建议填写
  • 额外排除选择器 – 自定义 CSS 排除非题目区域

风险与注意事项

  • 全域匹配 – 默认在所有网页生效，请务必在“设置”页填写白名单（如 wjx.cn, wj.qq.com），否则可能在网银/后台误操作
  • API Key 明文存储 – 勾选“保存到本地”后 Key 会明文写入扩展存储，共用电脑勿勾
  • 可能违反平台 ToS – 自动化填写可能被封号，风险自担
  • 自定义端点 – 请确保地址可信，防止 Key 泄露

常见问题

提取不到题目？
点“预览提取到的题目”看结果若缺失，调整“额外排除选择器”或关闭页面的混淆开关也可开调试模式看控制台日志
AI 总返回“暂无”？
脚本已拦截占位符，但模型太弱（如 glm-4-flash）时请换更强模型（如 gpt-4o-mini）或调低 temperature 到 0.2~0.3
跨页不继续？
检查“跨页”是否开启，且“自动点击下一页”打开若框架特殊，可手动点一下“下一页”，脚本会接管
速度怎么调？
在“填写”页下拉选档位，或展开“详细速度参数”微调（基础耗时、递减系数、抖动等）
会收集个人信息吗？
不会只与您配置的 AI 服务商通信，日志仅存内存，不落盘
